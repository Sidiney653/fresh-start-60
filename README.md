# Inglés Mapeado — Página de Vendas

Página de vendas em React + Vite (mesma estrutura da página de moldes).

## Rodar localmente
```
npm install
npm run dev
```

## Gerar a versão de produção
```
npm run build
```

## Onde editar
- `src/content.js` — textos da página
- `src/comercial.js` — preço, link do checkout (Hotmart) e garantia
- `public/assets/` — imagens do produto e dos bônus
